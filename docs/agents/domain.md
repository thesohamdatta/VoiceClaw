# Domain Docs

This project uses a single-context layout for domain documentation.

## Locations

- **Domain Language:** `CONTEXT.md` at the repo root.
- **Architecture Decisions:** `docs/adr/` directory.

## Consumer Rules

- Always read `CONTEXT.md` before starting a task to ensure consistent terminology.
- Refer to `docs/adr/` when making architectural changes to ensure alignment with past decisions.
